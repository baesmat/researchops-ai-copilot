# Five-Minute Demonstration Script

*Audience: senior research leadership. Assumption: the app is running with the three synthetic protocols loaded and one already analyzed (the lung study).*

**Minute 1 — The problem.**
"When a protocol arrives, five teams read the same hundred pages for different reasons. The questions interlock — imaging drives storage, storage drives governance — and the answers live in different sections. Today I'll show a colleague that never gets tired of the reading, shows its work, and knows what it doesn't know." → open **Dashboard**: documents ingested, analyzed, items awaiting clarification.

**Minute 2 — AI-assisted extraction.**
**Protocol Analysis** tab: walk the study identification and design blocks. Pause on any field: *"Planned enrollment — 120 participants, source page 3, and the system verified the passage supports the claim."* Point at a `Not specified in the protocol` value: "It flags gaps instead of inventing answers — that's the behavior you want from a colleague."

**Minute 3 — Operational planning.**
**Startup Checklist**: filter to `Protocol Required` — each task cites the protocol passage that forces it. Switch to `Needs Clarification`: the questions the team must answer before activation. Emphasize the third category, `AI Suggested`: "Clearly labeled hypotheses — the tool proposes, the room disposes." Note the one-click CSV export for the project tracker.

**Minute 4 — Research informatics.**
**Ask the Protocol**: ask "What data management requirements are described?" and "What infrastructure should IT discuss with the study team?" Show citations under each answer and a `grounded` badge. Ask something the document lacks: the assistant says so plainly and offers a *labeled* general suggestion. "Every answer is checkable in seconds — that's what makes AI usable in a research-governance context."

**Minute 5 — Enterprise readiness.**
**Reports**: generate the executive PDF — gaps, risks, source references, and a standing human-review requirement, no fabricated readiness score. Close on governance: local-only deployment, synthetic data, no PHI claims, and the path from this demo to a controlled pilot: *validate on our own protocols, behind our SSO, with a named owner.* "The technology is the easy part; the ask is a two-week controlled pilot to measure it."

**Backup questions to have run already:** imaging requirements, multi-site data sharing, missing-information summary.
